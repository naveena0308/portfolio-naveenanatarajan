Featured Project Live on Vercel

FinSight AI

Agentic Financial Budget Analyst

Answers questions about Tamil Nadu's Fiscal Management White Paper (2021–22 to 2025–26) with page-level citations. A LangGraph ReAct agent routes each question between vector search over 223 section-aware chunks and SQL over structured tables in Neon Postgres, and a verification agent re-checks figures against the source table. Includes a Chat Analyst and a Visual Dashboard. Frontend built with Next.js/React as part of my full-stack learning.

  • Ingestion: 121-page report parsed with PyMuPDF, keeping section and page citations.
  • Data layer: Neon PostgreSQL for SQL aggregation and verified lookups.
  • Agent: LangGraph ReAct with a verification step before each answer.
  • Deployment: Next.js app on Vercel.
